# Recipe: ComfyUI on MimicPC

Running ComfyUI on MimicPC (hosted GPU, Mike's saved template) for depth maps, masks and style samples, driven from Claude in Chrome. What gets run there is in `screens-layering.md` ("Depth occlusion") and `style-browser.md`. Starting, extending and stopping the machine is the person's, since it costs money.

## Gotchas
- **Some ComfyUI node packs break the MimicPC app for good** (2026-11-24, M5): 1038lab `ComfyUI-RMBG` pulled in `nobg`, which upgraded `transformers` to 5.x and `huggingface-hub` to 2.x (TBG-SAM3 needs below 5 and below 1.0), and PozzettiAndrea `ComfyUI-DepthAnythingV3` builds a pixi environment at every start and drags in GeometryPack (CGAL, Blender). After that the app never came back from Relaunch, even on new hardware, and had to be replaced. When adding a node pack, read its `requirements.txt` (and any `install.py` or prestartup script) first, install one at a time, and Relaunch to check before the next.
- **MimicPC's own disk fills before your storage does** (2026-11-24, M5): downloads stage in `/tmp` and Hugging Face caches in `/root/.cache`, on the machine's small disk, not the `/data` storage; several multi-GB downloads in a row hit "No space left on device" with 40 GB of storage free. A new machine starts with that disk empty. When pre-downloading weights, spread them over machines or let the GPU run fetch them.
- **SAM 3's weights are gated** (2026-11-24, M5): every SAM 3 node fetches `facebook/sam3`, which needs Meta's licence accepted and a Hugging Face login, and ComfyUI-Manager won't fetch files outside its list. Mike put `sam3.pt` from the ungated mirror `1038lab/sam3` into `models/sam3/` (the TBG loader reads it there; it can't read the safetensors copy). On a new MimicPC app, check `models/sam3/sam3.pt` first.
- **Reading ComfyUI's logs from the browser gets blocked** (2026-11-24, M5): Claude in Chrome refuses output that looks like a token, and ComfyUI's log and history carry Hugging Face URLs. Read prompt ids and statuses only (`pipOcc.status()` filters them).
- **ComfyUI-Manager installs want the cached list's entry** (2026-11-24, M5): posting a pack's entry from the remote node list to `/manager/queue/install` failed with KeyError 'version'. When installing a pack through the API, try taking its entry (id and version) from the Manager's cached list instead.
- **A pack the Manager doesn't list can go in by git URL** (2026-11-24, M5): the TBG DA3 pack wasn't in the Manager's list. When a pack is missing, try `/customnode/install/git_url` with its repo, after reading its requirements (the RMBG entry above).
- **ComfyUI-Manager's model list goes stale after an install** (2026-11-24, style bake-off): xinsir's SDXL depth ControlNet, installed through the Manager's API, didn't show in the loader until MimicPC's Relaunch. When a model you just installed is missing from a node's list, try Relaunch before reinstalling. The ComfyUI tab's page scripts were still there afterwards.
- **MimicPC's Extend box ignores a number that's only been typed** (2026-11-24, style bake-off): typing 30 and confirming added 1 minute. When the person extends the timer, type the minutes, press Tab, then confirm, and check the new end time.
- **MimicPC's 5-minute warning covers the Stop button** (2026-11-24, style bake-off): when stopping near the end of a session, close the warning popup first, then Stop and confirm Yes.
- **Size a run to the timer before queueing** (2026-11-24, style bake-off): on the T4, SDXL at 1344x768 took about 26 s an image at 24 steps and 31 s at 30. When a batch has to finish before MimicPC's time runs out, time one image first and pick steps from that.
- **A long `javascript_tool` call times out** (2026-11-24, M5): awaiting ComfyUI jobs inside one Claude in Chrome call failed after about 40 s. When waiting on a page, poll with short calls (`pipOcc.status()` every ~40 s).
- **Civitai is region-blocked from Mike's computer** (2026-11-24, style bake-off): its API answered 451 REGION_BLOCKED. When looking for checkpoints or LoRAs, search Hugging Face, or work from models Mike brings. Getting round the block (VPN, proxy, MimicPC as a relay) was declined.
- **Win: drive ComfyUI from its own page** (2026-11-24, M5): MimicPC's URL alone doesn't sign you in, but `fetch` from Claude in Chrome's `javascript_tool` in the open ComfyUI tab uses the page's session. That covered `/prompt`, `/history`, `/upload/image`, `/object_info` and the Manager endpoints, with no cookies handed over. `tools/depth/comfy_queue.js` and `tools/style_browser/comfy_queue.js` are built on it.
