# Story Room return files

Changes to the story made from the account that doesn't own the Story Room, as one JSON file per handover: `story-return-<handover id>.json`. The format is in the RETURN.md of the handover pack it answers (see `docs/story-room/handover.md`). Mike imports each file into the Story Room and accepts or rejects its changes there. Until a file is imported, nothing in it is part of the story.
