# Claims, holds and what actually happened (built 21 Nov)

Part of the world-lore item in visual-specs-plan.md (section 2), built early. Live version `1795264871-417f` (now superseded: see hooks-shots.md, `1795267757-4ed5`).

- Data on `entries`: `claims: [{k, text, by:[entry ids or free text]}]` and `truth: {state:"undecided"|"never"|"decided", text}`. Older records may still carry a `what_happened` string; `truthOf` reads it, and saving from the editor replaces it with `truth`.
- Holds are not stored. A faction's holds are worked out from every claim that names it (`holdsOf`).
- Record page (`claimsRecordHtml`, after the body): Claims with "Held by" links, Holds on factions, and a gold "What actually happened" card (shown when there are claims, a truth, or the record is an event). Backlinks add "holds a claim on it"; `linksOf` counts claim holders, so a game's brief scope pulls in the factions.
- Editor (`claimsEditorHtml`, `syncClaims`, `tidyClaims`, actions `cl-add`, `cl-del`, `tr-state` in `claimsAct`): one box per claim (text, plus "Held by" as ids or names, commas between; names resolve to ids on save, anything unmatched stays free text such as "a minority"), and a three-way state with a text box for the truth. Hidden for places and in-jokes unless they already have claims.
- Briefs: each record gets `Claim:` lines and factions get `Holds:` lines, plus a header line saying claims are unconfirmed and NPCs can be confidently wrong. The truth never goes in a brief. The Full Markdown export includes it, marked "Mike only". Christine's view only ever gets bodies, so claims and truths never reach her.
- Done since (21 Nov, hooks-shots.md): the Write tab's record tools can set claims and truths (truth needs Mike's exact words); NPC hooks and the contradiction check are built; claims now show "Believed by" from NPC hooks; `recordDump` (roleplay, Write tab) now includes claims with their keys, never the truth.
- World lore records added 21 Nov (all canon, series-wide, tag `world-lore`): the_most_damp_convocation, saint_ondril_the_overflowing, the_old_wellfellow, king_mothrag, the_drowned_emperor, house_of_fennimore_slough, third_unspooling_of_king_mothrag, the_great_unmoistening, the_treaty_of_wetfoot, the_schism_of_the_single_towel, reformed_church_of_the_damp, the_unwrung, the_frogmatists, the_order_of_the_spool. Mothrag is the house style for lore names.
