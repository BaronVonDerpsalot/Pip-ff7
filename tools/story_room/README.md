# Story Room page

`index.html` is the Story Room artifact's whole page (the series story bible; link and notes in `docs/story-room/`). It is kept here so either account can publish its own copy. The live artifact stays the original; this file is refreshed from it whenever the app changes, from the `app/index.html` inside a handover pack (Room → Export → Hand over).

The story itself is not in this file: it lives in the artifact's database, and moves between accounts as handover packs and return files (`docs/story-room/handover.md`).
